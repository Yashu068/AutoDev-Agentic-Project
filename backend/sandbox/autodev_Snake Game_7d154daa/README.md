# Snake Game Project
## Overview
The Snake Game project is a classic implementation of the popular Snake game, where a snake moves on a grid, eats randomly generated food to grow, and the game ends upon collision with walls or its own body. The game includes score tracking, speed adjustments, and a replay mechanism.

## Features
* Classic Snake game logic
* Randomly generated food
* Score tracking
* Speed adjustments
* Replay mechanism
* User-friendly interface

## Requirements
* Python 3.x
* Pygame library
* HTML, CSS, and JavaScript for the frontend

## Installation
1. Clone the repository using `git clone https://github.com/your-username/your-repo-name.git`
2. Install the required dependencies using `pip install -r requirements.txt`
3. Run the game using `python main.py`

## Usage
1. Open the game window using `python main.py`
2. Use the arrow keys to control the snake's direction
3. Eat the food to grow the snake and increase the score
4. Avoid colliding with the walls or the snake's own body
5. Press the arrow keys to change the snake's direction
6. The game will reset automatically after a collision

## Project Structure
* `requirements.txt`: list of dependencies
* `game.py`: game logic
* `main.py`: game entry point
* `index.html`: game interface
* `style.css`: game styling
* `script.js`: game interaction
* `README.md`: project documentation
